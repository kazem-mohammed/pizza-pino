 1) ما هذا المشروع؟ / What is this?
--------------------------------------------------------------------------------
موقع ويب كامل وفاخر لمطعم PIZZA PINO (بورسعيد، مصر) مبني بـ HTML5 + CSS3 +
JavaScript خالص (بدون مكتبات، بدون خطوة بناء، بدون سيرفر).

A complete, premium restaurant website built with pure HTML5 + CSS3 + vanilla
JavaScript — no frameworks, no build step, no backend. Ready to host on
GitHub Pages or any static host.

الهوية المختارة: "Signature Fusion Experience" (Concept 10) — الفائز من بين
10 تصاميم (انظر concepts.html و DESIGN-CONCEPTS.md).

 3) النشر على GitHub Pages / Deploy
--------------------------------------------------------------------------------
الطريقة أ — نشر المجلد مباشرة:
  1. أنشئ مستودعًا جديدًا على GitHub (مثال: pizza-pino).
  2. ارفع كل ملفات هذا المجلد إلى الفرع main.
  3. Settings ▸ Pages ▸ Source = "Deploy from a branch" ▸ Branch = main ▸ /root.
  4. انتظر دقيقة، ثم افتح: https://<username>.github.io/pizza-pino/

الطريقة ب — سطر الأوامر:
  git init
  git add .
  git commit -m "PIZZA PINO website"
  git branch -M main
  git remote add origin https://github.com/<username>/pizza-pino.git
  git push -u origin main
  (ثم فعّل Pages كما في الخطوة 3)

الطريقة ج — أي استضافة ثابتة: Netlify / Cloudflare Pages / Vercel
  اسحب المجلد وأفلته (drag & drop). لا يحتاج build command ولا start command.

لا يحتاج الموقع إلى: Node.js · npm · قاعدة بيانات · سيرفر · PHP.
جميع المسارات نسبية (relative) لذا يعمل داخل أي مجلد فرعي.

 4) معمارية الترجمة / Translation architecture
--------------------------------------------------------------------------------
ثلاث طبقات منفصلة تمامًا (مبدأ: لا تلمس البيانات الأصلية عند الترجمة):

  (1) UI_TRANSLATIONS  (translations.js)
      نصوص الواجهة: التنقل، الأزرار، البحث، الفوتر، رسائل الحالة.
      مترجَمة بالكامل لـ 26 لغة:
        en, it, ar, fr, de, es, ru, zh, ja, ko, pt, tr, el, nl, pl, hi, ur,
        id, ms, th, vi, sv, no, da, fi, he

  (2) LANGUAGES  (translations.js)
      سجل يحتوي 142 لغة، لكل لغة: الكود، الاسم الأصلي (native)، الاسم الإنجليزي،
      الاتجاه (ltr/rtl)، والعلم. المحدِّد يعرض الأسماء الأصلية مع البحث الفوري.

  (3) MENU_TRANSLATIONS  (translations.js) + menu-data.js
      أسماء/أوصاف الأصناف مفصولة عن الأسعار والمقاسات.
      • menu-data.js = البيانات الأصلية (الأسماء الأصلية + الأسعار + المقاسات).
      • MENU_TRANSLATIONS = ترجمات أسماء/أوصاف الأصناف (حاليًا: en / it / ar).

الشفافية (مهم — بدون مبالغة):
  • الترجمات الكاملة لنصوص الواجهة متوفرة لـ 26 لغة.
  • ترجمات أصناف المنيو الكاملة متوفرة لـ en/it/ar فقط.
  • بقية اللغات (حتى 142) تعمل عبر fallback تلقائي إلى الإنجليزية، دون كسر
    الواجهة. لا ندّعي ترجمة 142 لغة كاملة قبل توفّرها فعليًا.

قواعد صارمة مُطبّقة في الكود:
  • لا تتغيّر الأسعار أو العملة أو المقاسات أو الكميات عند تبديل اللغة.
  • تُحفظ أسماء العلامة/الأصناف التجارية كما هي.
  • لم تُخترع أي مكوّنات أو أوصاف أو أسعار أو أصناف.
  • الحقل needsReview:true يعلّم الأصناف التي تحتاج تأكيد المطعم.

خيار Mode B (API) — موثّق فقط، غير مُفعّل:
  لتفعيل ترجمة آلية للـ 142 لغة لاحقًا، استخدم وسيطًا آمنًا (proxy) على
  Cloudflare Worker / Netlify Function يخزّن مفتاح API في متغيّرات البيئة
  (Environment Variables) ولا يظهر أبدًا في المتصفح. أضف تخزينًا مؤقتًا
  (cache) و fallback إلى الإنجليزية. لا تضع أي مفتاح داخل script.js.

 5) بنية بيانات المنيو / Menu data structure
--------------------------------------------------------------------------------
الأقسام (11): Pizza · Soup · Salads · Pastas · Main Courses · Fish ·
              With / Rice & Side Dishes · Breakfast · Desserts · Drinks · Ice Cream

حقول كل صنف:
  id            معرّف فريد (يُستخدم كمفتاح ترجمة)
  cat           القسم
  en / ar       الاسم الإنجليزي / العربي
  desc{en,ar}   الوصف (عند توفّره)
  sizes[]       المقاسات مع الأسعار (للبيتزا: S / M / L)
  price         سعر مفرد (لغير البيتزا)
  img           اسم ملف الصورة في الجذر
  needsReview   true = البيانات تحتاج تأكيدًا من المطعم

المصدر: صور المنيو المرفقة عبر OCR + مراجعة يدوية. أي قراءة غير مؤكدة
مُعلَّمة بـ needsReview ولم يُخمَّن أي رقم.

 9) ملاحظات هامة للمطعم / Important notes for the restaurant
--------------------------------------------------------------------------------
• الشعار: لم يُرفع شعار متجهي/شفاف نظيف؛ استُخدم شعار نصّي (logo.svg) بالاسم
  الأصلي PIZZA PINO بدون أي إعادة رسم. يُفضّل تزويدنا بالشعار الأصلي (PNG شفاف
  أو SVG) لاستبداله.
• الأسعار: بعض الأصناف (خصوصًا البيتزا بالمقاسات، والمشروبات، والآيس كريم)
  قراءتها من الصور غير مؤكدة ومُعلَّمة needsReview — يُرجى تأكيد الأسعار.
• الصور: كل صور الأطباق هي صوركم الأصلية؛ لا توجد صور من الإنترنت ولا صور
  مُولّدة بالذكاء الاصطناعي. لم نتمكّن من ربط كل صورة بصنفها بدقّة (نقص بيانات)،
  لذا يُرجى تأكيد الصورة المناسبة لكل طبق.
• المسبّبات/الحساسية (حلال/نباتي/أليرجين/سعرات): لم تُخترع ولم تُضف أي معلومة
  غذائية غير مؤكّدة.
• ساعات العمل والسوشيال: غير متوفّرة في الصور — تُركت بحالة "سيتم التأكيد".
• ضريبة: الأسعار شاملة ضريبة الخدمة والقيمة المضافة (حسب المنيو الأصلي).
• الصفحة الرسمية للمنيو الممسوح متاحة في الجالبري (menu-page-1/2.jpg).
